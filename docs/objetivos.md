# Objetivos

## Objetivo general
Desarrollar una aplicación backend para la gestión de citas médicas de una clínica u hospital, que permita agendar y cancelar citas sin conflictos de horario.

## Objetivos específicos
1. Modelar la información de médicos, especialidades, pacientes, horarios de atención y citas en una base de datos relacional.
2. Implementar una API REST para consultar médicos y pacientes, y agendar, cancelar y listar citas.
3. Garantizar que no se agenden citas fuera del horario del médico ni solapadas con otras citas.
4. Verificar las reglas de negocio con pruebas automáticas.
5. Dejar el proyecto reproducible: cualquier persona debe poder clonarlo y ejecutarlo siguiendo el README.

## Alcance
*Incluye:* gestión de citas, validaciones de negocio, datos de prueba y pruebas unitarias.

*No incluye (por ahora):* autenticación y roles, interfaz gráfica, recordatorios por correo o WhatsApp, reportes y múltiples sedes.
